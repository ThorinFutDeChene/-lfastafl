# Álfastafl

Jeu libre de tafl Viking-fantasy (GPL-3.0), destiné à Ubuntu et au réseau local.

## État

Développement en cours. La branche `main` est réservée aux versions stables validées ; les développements et tests sont effectués sur `dev`.

Modes prévus : Historique (reconstruction Tawlbwrdd), Classique (Fetlar 2018), Compétition (Copenhague). Hôte Ubuntu, joueurs et spectateurs sur réseau local via une application ou un navigateur/QR code. Tournois et projection cinématographique.

La première version stable n'est pas encore publiée.
